## Assets

All gameplay meshes, materials, lighting, terrain, vegetation, UI layout, and the project icon SVG are **original procedural / code-generated content** created for this repository. No third-party texture packs, 3D models, or audio were imported.

- Terrain: `FastNoiseLite` heightmap + vertex colors + `NoiseTexture2D`
- Vegetation / rocks / player / crystals: Godot built-in primitive meshes (`CylinderMesh`, `SphereMesh`, `CapsuleMesh`, `PrismMesh`, `BoxMesh`) with `StandardMaterial3D`
- Sky: `ProceduralSkyMaterial`
- Icon: hand-authored SVG (CC0 / public domain dedication for the icon artwork; project overall remains MIT)

No CC0 external packs were required; none are bundled.
